# GreenBite - Frontend (React + Vite)

Este repositorio contiene el componente frontend de la plataforma **GreenBite**, una solución sustentable para la gestión de suscripciones de alimentos. [cite_start]El desarrollo se alinea con los requerimientos de escalabilidad, disponibilidad del 99,9% y tolerancia a fallos definidos en la arquitectura de microservicios del proyecto[cite: 34, 66].

## 🌿 Descripción del Proyecto
[cite_start]GreenBite es una plataforma diseñada para conectar productores sustentables con consumidores finales, optimizando la logística para reducir la huella de carbono. [cite_start]Este frontend permite la interacción con el catálogo de productos y la gestión de planes de suscripción de manera eficiente a través de una interfaz moderna y reactiva[cite: 4, 39].

## 🛠️ Especificaciones Técnicas (NPM Standard)
Siguiendo las instrucciones de la Evaluación Parcial 2, este componente ha sido estandarizado bajo el modelo de empaquetado NPM:
- [cite_start]**Vite & React**: Utilizado para un renderizado eficiente y un entorno de desarrollo de alto rendimiento[cite: 4, 41].
- **Arquitectura de Componentes**: Estructura modular y escalable (ej. `SubscriptionCard`) que facilita el mantenimiento y la reutilización de código.
- **Estandarización NPM**: Configuración completa de scripts para instalación, desarrollo y empaquetado profesional (Build).
